## Jebakan baru (sesi ini; jangan diulang)

- **`:global(X) .kelas` di `<style scoped>` Vue dikompilasi menjadi `X{…}` saja** — kelasnya hilang. Aturan
  tema gelap tidak pernah berlaku sejak 1.5 (alasan pending, "Belum disalin"). Tulis
  `[data-bs-theme='dark'] .kelas` biasa di style scoped (atribut scope menempel di `.kelas`). Periksa CSS
  hasil build: `grep -o "\[data-bs-theme=dark\][^{]*{[^}]*}" apps/web/dist/assets/*.css`.
- **Daftar berkas e2e di CI basi** sejak 1.3. Sekarang `pnpm e2e` tanpa argumen; jangan kembali ke daftar nama.
- **`getByRole(…, { name: 'Ditutup' })` di Playwright mencocokkan sebagian teks** ("Pulih · siap ditutup").
  Pakai `exact: true`.
- **Trigger BEFORE yang memperbarui baris induk berjalan sebelum CHECK baris itu sendiri.** Entri ke Ditutup
  tanpa penyebab ditolak `tickets_closure` lebih dulu dari `ticket_actions_close`. Untuk menguji satu CHECK,
  pakai kasus yang hanya bisa ditolak CHECK itu (entri tanpa perpindahan status).
- **`width: 1%` sel tabel ikut ke mode blok bertumpuk** (flex-basis `auto` membaca `width`): nomor NPR
  terpotong di 375 px. Setel `width: auto` di media query blok.
- **Uji K21 di database memakai peran pembuat entri** (`users.role` milik `created_by`). Helper uji yang
  menulis entri langsung atas nama pembuat NPR (L1) akan ditolak bila NPR punya TT; pakai
  `closeTicketDirect(…, { closedBy: idL2 })` dan `closeTroubleTicketDirect` di `apps/api/test/fixtures.ts`.
- **Container dimulai ulang menjelang akhir sesi**: PostgreSQL 18 mati, aplikasi :8080 hilang.
  `pg_ctlcluster 18 main start` sebelum uji.
- `git rev-parse --short A B` gagal ("Needed a single revision"); panggil satu per satu.
