## Menyiapkan container baru

Perintah Node 26 + PostgreSQL 18 di [handoff R0](2026-11-20-handoff-r0.md#menyiapkan-container-baru-tanpa-docker)
tetap berlaku dan dipakai sesi ini tanpa perubahan. Tambahan:
- Container sesi cloud **sering dimulai ulang**; setelah itu PostgreSQL mati
  (`pg_ctlcluster 18 main start`) dan server aplikasi hilang. Cek dulu sebelum menguji.
- Ada PostgreSQL 16 bawaan yang mati di port yang sama; abaikan.
- Skrip Playwright untuk tangkapan layar di luar repo butuh
  `NODE_PATH=<repo>/apps/web/node_modules:/opt/node22/lib/node_modules` (paket `playwright` global
  ada di `/opt/node22/lib/node_modules`).
- Biner headless shell yang dipakai CI (untuk `E2E_CHROMIUM_PATH`):
  `/opt/pw-browsers/chromium_headless_shell-1243/chrome-headless-shell-linux64/chrome-headless-shell`
  (handoff R0 hanya menyebut folder induknya).

## Jebakan baru (sesi ini; jangan diulang)

- **`ON DELETE RESTRICT` memberi kode `23001`, bukan `23503`.** `isInUseError` di
  `master-input.ts` menangani keduanya; hapus customer yang punya pengguna sempat 500.
- **Vue `watch([a, b], cb, { immediate: true })`**: nilai lama pada panggilan pertama adalah larik
  berisi `undefined`, bukan `undefined`. Pemuatan sekali-di-awal jangan digantung di situ.
- **Aksi baris yang selesai belakangan menimpa mode baris yang baru dibuka** (CI run #87 merah):
  `MasterTable.vue` kini menonaktifkan tombol baris selama aksi dan hanya mengembalikan mode bila
  belum diganti. Uji regresinya menahan jawaban API dengan `page.route`; pakai pola itu untuk race UI.
- **Impor yang menulis semua kolom menghapus data di kolom yang tidak ada di berkas** (T52) —
  ditemukan dari tangkapan layar pratinjau, bukan dari uji. Periksa tangkapan layar dengan teliti.
- Kelas `.steps` bentrok dengan komponen Tabler; beri nama kelas sendiri yang spesifik.
- `pnpm add --config.minimum-release-age=20160` menolak seluruh pemasangan karena dependensi lama
  repo (mis. vite 8.3.8) sendiri belum 2 minggu. Pasang biasa, lalu cek umur tiap paket baru di
  lockfile dengan `pnpm view <paket> time --json`.
- Heredoc Bash berisi `$`/backtick bisa ditolak pemeriksa keamanan sebagai "rm"; untuk sunting
  kode pakai alat Edit/Write.
- Supertest untuk unduhan biner: `.responseType('blob')` (bukan pengurai sendiri — galat tipe).
- Log CI lengkap: `get_job_logs` dengan `return_content: false` memberi URL; unduh dengan `curl`
  lalu `grep`. `return_content: true` hanya memberi ekor log container.
- Uji layar menulis data ke database `tyio` lokal (remote `E2E-…`, customer uji); itu wajar.
  Run e2e yang gagal di tengah meninggalkan baris "Uji Layar …"; bersihkan dengan konteks audit
  `manual` bila mengganggu tangkapan layar.
