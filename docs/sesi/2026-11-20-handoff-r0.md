## Menyiapkan container baru (tanpa Docker)

Sesi cloud tidak punya Docker. Yang tersedia bawaan: pnpm 12.21.0 (`/opt/node22/bin/pnpm`),
Chromium Playwright (`/opt/pw-browsers/chromium`, headless shell di `/opt/pw-browsers/chromium_headless_shell-1243/`).
Node 26 dan PostgreSQL 18 perlu dipasang (sesi ini memasangnya dengan perintah berikut):

```bash
# Node 26.13.1 (.nvmrc = 26)
mkdir -p /opt/node-dl /opt/node26 && cd /opt/node-dl && V=v26.13.1 F=node-v26.13.1-linux-x64.tar.xz
curl -sSfO https://nodejs.org/dist/$V/$F && curl -sSfO https://nodejs.org/dist/$V/SHASUMS256.txt
grep " $F\$" SHASUMS256.txt | sha256sum -c - && tar -xJf $F -C /opt/node26 --strip-components=1
export PATH=/opt/node26/bin:$PATH   # di setiap perintah shell

# PostgreSQL 18 (arsip Ubuntu http sering 503: pakai mirror https kernel.org)
install -d /usr/share/postgresql-common/pgdg
curl -sSf -o /usr/share/postgresql-common/pgdg/apt.postgresql.org.asc https://www.postgresql.org/media/keys/ACCC4CF8.asc
. /etc/os-release
echo "deb [signed-by=/usr/share/postgresql-common/pgdg/apt.postgresql.org.asc] https://apt.postgresql.org/pub/repos/apt ${VERSION_CODENAME}-pgdg main" > /etc/apt/sources.list.d/pgdg.list
printf 'deb https://mirrors.edge.kernel.org/ubuntu %s main universe\ndeb https://mirrors.edge.kernel.org/ubuntu %s-updates main universe\n' "$VERSION_CODENAME" "$VERSION_CODENAME" > /etc/apt/sources.list.d/ubuntu-https-mirror.list
apt-get update -qq; DEBIAN_FRONTEND=noninteractive apt-get install -y -qq --no-install-recommends postgresql-18 shellcheck
pg_createcluster 18 main --port 5432 --start -- --auth-local=trust --auth-host=scram-sha-256 || pg_ctlcluster 18 main start
su postgres -c "psql -p 5432 -qc \"CREATE ROLE tyio LOGIN PASSWORD 'tyio' CREATEDB;\" -c 'CREATE DATABASE tyio_test OWNER tyio;' -c 'CREATE DATABASE tyio OWNER tyio;'"

cd <repo> && pnpm install --frozen-lockfile && pnpm build
```

Setelah container dimulai ulang PostgreSQL mati: `pg_ctlcluster 18 main start`.

## Jebakan yang sudah ditemukan (jangan diulang)

- `pkill -f "node dist/main.js"` di perintah yang sama dengan `node dist/main.js` ikut membunuh
  shell-nya sendiri. Matikan per PID: `for p in $(pgrep -f "dist/main.js"); do kill $p; done`.
- Soket gpg-agent gagal bila `GNUPGHOME` berjalur panjang (> ~100 karakter, mis. di scratchpad);
  skrip memakai `/tmp/tyio-gpg.*`.
- libpq tidak membaca URL dari `PGDATABASE`; `backup.sh` memakai `BACKUP_DATABASE_URL`.
- `cmd | grep -q` dengan `set -o pipefail` bisa gagal karena SIGPIPE; pakai pencocokan string.
- Collation database lokal "C" (BPD < Bank); urutan nama customer dilakukan di aplikasi.
- vue-router: rute anak berpath kosong (Overview) dianggap aktif di semua halaman; menu aktif
  dihitung sendiri di `SideNav.vue`.
- Locale `id-ID` menulis jam "20.49"; ATURAN.md menuntut "20:49" (`ZoneClock.vue`).
- Konteks uji Playwright selalu "incognito"; `Page.getInstallabilityErrors` melaporkan
  `in-incognito` yang memang dikecualikan di `shell.spec.ts`.
- CI pernah merah karena mirror Ubuntu 503 saat `playwright install --with-deps` (run #69): itu
  gangguan luar, bukan kode. Ulangi job sekali bila log menunjukkan 503.
- Tulisan ke tabel yang diaudit tanpa konteks audit **ditolak database** (T25): di uji pakai
  `asOperator`/`operatorQuery`/`insertUser` dari `apps/api/test/fixtures.ts`; di kode pakai
  `auditedTransaction`. Tabel baru: `tenant_id` + `SELECT audit_enable(...)`, dan endpoint baru
  wajib `@TenantScoped()`/`@NoTenantData()` + probe di `tenant-isolation.test.ts`
  ([aturan](../pengembangan/tenant-dan-audit.md)).
