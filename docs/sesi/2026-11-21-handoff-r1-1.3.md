## Jebakan baru (sesi ini; jangan diulang)

- **Squash merge lalu merge `main` ke branch yang masih membawa commit asli → "konflik" di semua berkas
  yang diubah kedua sisi** (12 berkas di branch 1.3), padahal isinya sama. Cara aman: pastikan
  `git diff --quiet origin/main <head lama branch PR>` (isi `main` = head lama), lalu
  `git checkout --ours -- $(git diff --name-only --diff-filter=U)` dan buktikan
  `git diff --cached --quiet <head branch sebelum merge>` sebelum commit.
- **Mengubah migrasi yang belum dirilis setelah sempat dijalankan di `tyio_test`**: global setup memakai
  `down` versi baru untuk menurunkan versi lama dan gagal ("function … does not exist"). Bersihkan objek
  versi lama di database uji lokal saja (DROP TABLE + hapus baris di `migrations`). Migrasi yang sudah di
  `main` tidak boleh diubah; buat migrasi baru.
- **Pergantian bulan tidak bisa diuji bila nomor dihitung dari `now()`.** Itu sebabnya nomor dibuat
  trigger dari `created_at`: uji menyisipkan NPR dengan `created_at` tertentu (31 Okt 23:30 WIB, 31 Des
  22:30 WIB). Pakai pola ini untuk TT (1.5b) dan jam SLA (4.1).
- **Peringatan "masih ada tiket terbuka" hanya di layar bisa terlewat bila dua orang menyimpan
  bersamaan.** Server mengunci baris remote (`FOR NO KEY UPDATE OF r`, bukan `FOR UPDATE` dan bukan
  tanpa `OF`: tanpa `OF`, baris tenant dan jarkom yang di-join ikut terkunci). Uji serentaknya: 8
  permintaan paralel → tepat 1 tersimpan.
- `AppLayout.vue` memindahkan fokus ke isi halaman setiap pindah rute (aksesibilitas). Jangan autofocus
  isian saat halaman dibuka: fokusnya langsung direbut (uji `toBeFocused` gagal).
- Rute `/tiket/:id` sempat menangkap `/tiket/NPR-CONTOH` yang dipakai `shell.spec.ts` sebagai contoh
  alamat tidak ada → rute dibatasi pola UUID. Periksa uji "halaman tidak ditemukan" saat menambah rute
  berparameter.
- `.alert-warning` Tabler mewarnai **seluruh teks** kuning (kontras buruk di terang dan gelap); set
  `color: var(--tblr-body-color)` dan biarkan ikon saja yang kuning. Ditemukan dari tangkapan layar.
- Playwright `getByRole('region', { name: 'Lokasi' })` juga cocok dengan "Kontak di lokasi" (substring);
  pakai `exact: true`.
- Di uji layar, `page.request` membawa cookie sesi halaman dan lolos penjaga origin (tanpa header Origin),
  jadi dipakai untuk menyiapkan data lewat API (impor remote unik per run, NPR "dari operator lain").
- Uji layar menulis ke database `tyio` lokal: remote `E2E-NPR-<run>-*` dan NPR-nya; penghitung nomor
  BNA/VSAT ikut naik. Itu wajar.
